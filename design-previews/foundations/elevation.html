Elevation

Exactly four tiers. Don't invent a fifth — if something needs to feel "more elevated" than Modal, the problem is the layout, not the shadow.

Flat
none — inline content
Raised
buttons, inputs at rest
Overlay
popovers, dropdowns, toasts
Modal
dialogs, sheets, drawers

Modal scrim

Content sits above --shadow-scrim (oklch(0 0 0 / 0.4))
