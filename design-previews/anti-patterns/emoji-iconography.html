Anti-pattern · DS-SLOP-005

Emoji as UI iconography

Emoji standing in for real icons — as feature-card glyphs, list bullets, or button affordances — reads as placeholder work. Use the icon set instead (see references/iconography.md). Emoji in content the user authored is fine; emoji the interface ships as its own chrome is not.
