Anti-pattern · DS-TABLE-001, DS-TABLE-004

Overflow on the table wrapper

A sticky header sticks to its nearest scroll container. overflow-x: auto makes the wrapper one on both axes, so the header sticks to the wrapper and scrolls away with the page. overflow: auto clip does not fix it: clip computes to hidden, which is still a scroll container. Scroll inside each box to see what the header does.
