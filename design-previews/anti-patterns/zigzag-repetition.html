Anti-pattern · DS-SLOP-006

Zigzag repetition

Alternating image-left / image-right "zigzag" content sections are fine up to two in a row. A third consecutive one must break the pattern — change the layout family, go full-bleed, or cluster differently. Endless zigzag is what an agent produces when it has one layout idea and N sections to fill.

Avoid — a third zigzag in a row

Section one

Image left, copy right.

Section two

Image right, copy left.

Section three

Same pattern again — nothing signals this section is different from the last two.

Instead — the third section breaks the pattern

Section one

Image left, copy right.

Section two

Image right, copy left.

Section three goes full-bleed instead

A genuine break in rhythm, not a third repetition.
