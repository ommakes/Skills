Anti-pattern · DS-SLOP-008

Symmetry as the only rhythm

Every section the same width, same padding, same alignment, same vertical rhythm, top to bottom. Even at low VARIANCE, a page needs some change in pace — a full-bleed break, a tighter cluster, a wider gutter. Uniformity from top to bottom is a tell even when each individual section is fine.

Avoid — identical rhythm throughout

Section one

Same padding, same width, same alignment as every other section.

Section two

Same padding, same width, same alignment as every other section.

Section three

Same padding, same width, same alignment as every other section.

Instead — a change in pace

Section one

Standard width and padding.

A tighter, narrower cluster

Deliberately smaller to signal a supporting aside, not a peer section.

A full-bleed break

Escapes the page gutter entirely — the one place the rhythm changes on purpose.
