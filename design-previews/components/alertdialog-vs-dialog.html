AlertDialog vs Dialog

role="alertdialog" gives assistive tech a higher-urgency announcement than a plain dialog. Never use a Toast for this — it auto-dismisses, so the confirmation can be missed entirely.

Use · AlertDialog

Irreversible action. Requires an explicit choice before it can be dismissed.

Not · plain Dialog

No elevated urgency signal to screen readers — the user may not register that this is destructive.
