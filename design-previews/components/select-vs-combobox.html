Components · Job 6 · Choose from a list

Select vs Combobox

Combobox on a short list adds friction the user doesn't need — typing to filter 5 options is slower than scanning them. Reach for Combobox once the list is long enough that scanning stops working (roughly 8+) or search is genuinely useful.

Select · < 8 items

Four options — scanning is faster than typing.

Combobox · 8+ / searchable

Eight-plus teammates — typing to narrow beats scrolling.
